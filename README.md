# Flowcell Plotter

A browser-based flowcell data plotting tool. It runs entirely in the browser and does not require a server or package installation.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the main branch and the `/ (root)` folder, then save.

GitHub will provide the public website link after deployment finishes.

## Use

Choose the flowcell folder, add one or more material lines, configure each line's legend name, color, and style, then draw the IV, Break, and Hold charts.

All uploaded data is processed locally in the browser. Files are not uploaded to a server.
